# teacher-dashboard

Кабинет учителя — учебный проект из хэндбука Яндекса по Python.
Раздел **«Обработка запроса с интерфейса»** (задачи 3.1–3.4).

## Что это

Интерфейс, в котором учитель выбирает ученика из класса и видит статистику
по всем выданным и пройденным тестам: процент выполнения, правильные ответы,
время прохождения и даты выдачи.

## Стек

- **Frontend:** HTML, CSS, чистый JavaScript (без фреймворков)
- **Backend:** Python (в разработке)
- **Данные:** CSV-файлы (9 штук: users, classes, tasks, tests, attempts...)

## Авторство и инструменты

- **Backend (Python)** — пишется самостоятельно, в рамках прохождения хэндбука.
- **Frontend** — вёрстка и JS-логика написаны **с помощью ИИ-ассистента DeepSeek**
  (`chat.deepseek.com`). Архитектура, стили, логика отрисовки и работы с данными
  сгенерированы ассистентом по макету и требованиям задачи.
- **Идея, постановка задачи и данные** — из хэндбука Яндекса
  «Python-разработчик» (раздел «Обработка запроса с интерфейса»).

Проект учебный. Цель — разобраться с полным циклом: от CSV-данных
до отображения их в браузере, включая слой API и бизнес-логику на Python.

## Структура проекта

- **backend/** — Python-бэкенд
  - **backend/data/** — CSV-файлы с данными
  - **backend/app.py** — точка входа (Flask)
  - **backend/handlers.py** — бизнес-логика (задачи 3.1–3.4)
  - **backend/requirements.txt** — зависимости Python
- **frontend/** — клиентская часть
  - **frontend/index.html** — разметка страницы
  - **frontend/css/style.css** — стили
  - **frontend/js/api.js** — работа с данными (fetch)
  - **frontend/js/render.js** — отрисовка HTML
  - **frontend/js/main.js** — точка входа, связка
  - **frontend/assets/** — статика (пока пусто)

## Как запустить

### Frontend

Открыть `frontend/index.html` в браузере или запустить через Live Server
в VS Code.

Пока данные берутся из мока внутри `frontend/js/api.js` — бэкенд ещё в разработке.

### Backend

Пока реализована только логика обработки данных — файл `backend/handlers.py`.
